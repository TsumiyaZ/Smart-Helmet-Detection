# Smart-Helmet-Detection

## เตรียมโปรเจกต์ก่อนเริ่มใช้งาน

### 1. ดาวน์โหลดโปรเจกต์

ถ้ายังไม่มีโค้ดในเครื่อง ให้เปิด PowerShell แล้วรัน:

```powershell
git clone https://github.com/TsumiyaZ/Smart-Helmet-Detection.git
cd Smart-Helmet-Detection
```

ถ้าเปิดโปรเจกต์นี้อยู่แล้ว ให้เปิด Terminal ที่ **โฟลเดอร์หลักของโปรเจกต์** ซึ่งเป็นตำแหน่งเดียวกับไฟล์ `requirements.txt` ก่อนทำขั้นตอนถัดไป

### 2. ติดตั้งโปรแกรมที่โค้ดต้องใช้

ตรวจว่าเครื่องเรียก Python ได้ แล้วติดตั้งแพ็กเกจจาก `requirements.txt`:

```powershell
python --version
python -m pip install -r requirements.txt
```

คำสั่งนี้ติดตั้ง `numpy`, `Pillow`, `ultralytics`, `opencv-python` และ `streamlit` ซึ่งใช้กับโมเดล หน้าเว็บ และการประมวลผลวิดีโอ ติดตั้งครั้งเดียวต่อ Python environment ที่ใช้ทำงาน

### 3. วางไฟล์โมเดล

วางไฟล์ `best.pt` ไว้ที่โฟลเดอร์หลักของโปรเจกต์ หรือใน `weights/best.pt` ฟังก์ชันใน `src/detection.py` จะค้นหาโมเดลจากตำแหน่งเหล่านี้

## คลาสที่โมเดลตรวจจับ

- `0`: With Helmet
- `1`: Without Helmet

## เปิดเว็บแอป

จากโฟลเดอร์หลักของโปรเจกต์ รัน:

```powershell
python -m streamlit run app.py
```

จากนั้นเปิด URL ที่ Streamlit แสดงในเทอร์มินัล (ปกติคือ `http://localhost:8501`)

### ตรวจภาพ

เลือกแท็บ **ตรวจภาพ** อัปโหลด JPG, PNG หรือ WEBP ปรับค่าความมั่นใจได้ แล้วกด **ตรวจภาพ** หน้าเว็บแสดงภาพที่วาดกรอบ รายการประเภท คะแนนความมั่นใจ และจำนวนกรอบที่พบ หากไม่พบกรอบจะแจ้งว่าไม่พบวัตถุที่โมเดลรู้จัก

### ตรวจวิดีโอ

เลือกแท็บ **ตรวจวิดีโอ** อัปโหลด MP4, AVI, MOV หรือ MKV แล้วกด **ประมวลผลวิดีโอ** ระบบตรวจทีละเฟรมและแสดงความคืบหน้า เมื่อเสร็จจะเล่นและให้ดาวน์โหลดผลเป็น MP4 ระยะเวลาประมวลผลขึ้นกับความยาวคลิปและเครื่องที่ใช้

ตัวเลือก **ปรับภาพก่อนตรวจ** จะปรากฏเมื่อมี `src/preprocessing.py` ซึ่งส่งออกฟังก์ชัน `preprocess_image(image_rgb, method="default")` ตามข้อตกลงของทีม หากไม่มีโมดูลนี้ ระบบตรวจภาพเดิมได้ตามปกติ

## หมายเหตุ

ก่อนนำโมเดลไปใช้งาน ให้ตรวจว่าติดตั้ง dependencies สำเร็จและไฟล์ `best.pt` อยู่ในตำแหน่งที่ระบุไว้ คำสั่งติดตั้งต้องรันจาก Python environment เดียวกับที่ใช้เปิดโปรเจกต์

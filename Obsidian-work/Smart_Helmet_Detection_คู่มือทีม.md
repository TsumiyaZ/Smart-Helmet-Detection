# Smart Helmet Detection — คู่มือทีม

> [!summary] งานของทีม
> ทำระบบที่รับภาพหรือวิดีโอ ตรวจว่ามีการสวมหมวกนิรภัยหรือไม่ แสดงกรอบและผลตรวจ แล้วอธิบายได้ว่าระบบทำงานอย่างไรและประเมินผลอย่างไร

> [!important] ข้อกำหนดจากรูปที่ 1
> - โจทย์ระบุสมาชิก **ประมาณ 4 คน**; ทีมนี้มี **5 คนตามที่ตกลงกัน** จึงแบ่งงานให้ทั้ง 5 คนมีชิ้นงานและมีสิ่งส่งต่อให้ทีม
> - ต้องใช้วิธีปรับภาพที่เกี่ยวข้องกับปัญหาอย่างน้อย **1–2 วิธี** พร้อมอธิบายและแสดงผลก่อน/หลัง
> - ต้องใช้วิธี Computer Vision หรือโมเดล AI ที่เหมาะกับงาน
> - ต้องมีเว็บแอปที่เปิดสาธิตได้จริง รับภาพและวิดีโอหรือกล้องตามที่ทีมเลือก ประมวลผล แล้วแสดงผล
> - ต้อง **ประเมินผล** ด้วยตัวเลขและภาพตัวอย่าง ไม่ใช่แสดงเพียงภาพที่ตีกรอบแล้ว
> - ส่ง source code และ README ผ่าน GitHub
> - วันนำเสนอที่ระบุในโจทย์: **2 พฤศจิกายน 2569**

## ลำดับใหญ่ของงาน

1. ตกลงว่าจะตรวจอะไรและต้องมีป้ายกำกับแบบใด
2. คนที่ 2 หาและตรวจชุดภาพ ก่อนส่งให้คนที่ 3
3. คนที่ 3 ฝึกโมเดลและส่งไฟล์โมเดลให้ทีม
4. คนที่ 4 ทดลองปรับภาพและวัดผลโดยใช้ข้อมูลชุดเดียวกัน
5. คนที่ 3 ทำวิธีเรียกโมเดลที่คนที่ 1 และ 5 ใช้ร่วมกันได้
6. คนที่ 1 ทำหน้าเว็บสำหรับตรวจภาพ
7. คนที่ 5 ต่อการตรวจทีละภาพให้ทำงานกับวิดีโอ และรวบรวม README/หลักฐาน
8. ทุกคนช่วยตรวจส่วนของตัวเอง แล้วทีมซ้อมสาธิต

> [!warning] จุดที่ต้องตกลงก่อนเริ่มฝึก
> ตรวจชื่อป้ายกำกับในชุดภาพจริงก่อน เช่น `helmet` และ `no_helmet` ถ้าข้อมูลไม่มีป้าย `no_helmet` โมเดลจะเรียนรู้การตรวจ “ไม่สวมหมวก” จากชุดนั้นโดยตรงไม่ได้

## วิธีทำงานร่วมกัน

- เจ้าของแต่ละส่วนส่งไฟล์ตัวอย่างและวิธีเรียกให้คนที่จะนำไปใช้ อย่ารอจนงานเสร็จทั้งหมด
- คุยกันทันทีเมื่อชื่อคลาส รูปแบบภาพ หรือชื่อไฟล์ไม่ตรงกัน
- เก็บภาพทดสอบที่ไม่ได้ใช้ฝึกไว้ต่างหาก เพื่อดูว่าโมเดลทำงานกับภาพใหม่ได้หรือไม่
- คนที่ทำส่วนหนึ่งตรวจส่วนนั้นเอง คนที่ 5 รวบรวมปัญหาและตรวจการทำงานตั้งแต่ต้นจนจบ
- ถ้า Dataset หรือโมเดลยังไม่พร้อม ให้ทำหน้าเว็บ/โครงวิดีโอด้วยข้อมูลตัวอย่างชั่วคราว แต่ต้องเปลี่ยนเป็นผลจากโมเดลจริงก่อนสาธิต

## สิ่งที่ต้องมีตอนส่งงาน

- ชุดภาพและคำอธิบายที่มา/ป้ายกำกับ/การแบ่งข้อมูล
- โมเดลที่ฝึกแล้วและวิธีเรียกใช้
- วิธีปรับภาพอย่างน้อยหนึ่งวิธี พร้อมเหตุผลและผลเปรียบเทียบ
- ผลวัดโมเดลบนภาพที่ไม่ได้ใช้ฝึก
- เว็บที่รับภาพและแสดงผลตรวจจับ; เพิ่มวิดีโอเมื่อระบบพร้อม
- โค้ด, รายการโปรแกรมที่ต้องติดตั้ง, README, ภาพหน้าจอ และวิดีโอสาธิต

### หลักฐานที่ควรมีในโฟลเดอร์เอกสาร

- ตารางสรุปชุดข้อมูลและภาพตัวอย่างที่เห็นป้ายกำกับ
- ภาพต้นฉบับเทียบกับภาพหลังปรับ พร้อมชื่อวิธีที่ใช้
- ตารางผลประเมินที่คัดค่าจากการรันจริง และภาพตัวอย่างที่ตรวจถูก/พลาด
- ภาพหน้าจอหน้าเว็บ และคลิปผลลัพธ์ที่เปิดเล่นได้
- README ที่เพื่อนซึ่งไม่ได้เขียนโค้ดส่วนนั้นสามารถทำตามได้

## เริ่มตรงนี้

1. ทุกคนตกลงคำตอบของระบบและชื่อคลาสที่ต้องการ
2. คนที่ 2 หา Dataset ตัวเลือกและเปิดภาพ/ป้ายกำกับให้ทีมดู

4. คนที่ 4 ดูคุณภาพภาพและเลือกวิธีปรับภาพที่จะทดลอง
5. คนที่ 1 ทำหน้าเว็บเปล่า ส่วนคนที่ 5 เตรียมคลิปสั้นสำหรับทดสอบ
6. เมื่อ Dataset ผ่านการตรวจแล้ว คนที่ 3 จึงเริ่มฝึกโมเดลจริง

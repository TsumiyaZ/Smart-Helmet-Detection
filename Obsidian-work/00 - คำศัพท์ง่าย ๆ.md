# คำศัพท์เทคนิคอธิบายง่าย ๆ

- **Dataset / ชุดข้อมูล:** รูปภาพและป้ายกำกับที่ใช้สอนและตรวจโมเดล
- **ป้ายกำกับ (label):** คำตอบที่คนใส่ให้ภาพ เช่น ชื่อสิ่งของและกรอบรอบสิ่งนั้น
- **คลาส (class):** ประเภทที่โมเดลต้องแยก เช่น `helmet` หรือ `no_helmet`
- **โมเดล (model):** โปรแกรมที่เรียนรู้จากภาพตัวอย่างแล้วใช้ตรวจภาพใหม่
- **ฝึก (train):** ให้โมเดลดูตัวอย่างพร้อมคำตอบเพื่อให้มันเรียนรู้
- **โมเดลที่ฝึกไว้แล้ว (pretrained):** โมเดลที่เริ่มเรียนรู้มาก่อน แล้วนำมาฝึกต่อกับภาพหมวกของทีม
- **ฝึกต่อ (fine-tune):** ปรับโมเดลที่ฝึกไว้แล้วให้รู้จักคลาสของโครงงาน
- **ทำนาย/ตรวจภาพ (predict):** ให้โมเดลตรวจภาพใหม่และคืนสิ่งที่พบ
- **กรอบตรวจจับ (bounding box):** สี่เหลี่ยมที่ล้อมสิ่งที่โมเดลพบ
- **คะแนนความมั่นใจ (confidence):** คะแนนที่บอกว่าโมเดลมั่นใจแค่ไหน เช่น 0.90 คือ 90 เปอร์เซ็นต์
- **Train / Validation / Test:** ภาพสำหรับฝึก / ภาพสำหรับดูผลระหว่างทำ / ภาพเก็บไว้ตรวจผลรอบสุดท้าย
- **ปรับภาพ (preprocessing):** เปลี่ยนภาพก่อนให้โมเดลดู เช่น เพิ่มความชัดหรือปรับแสง
- **ค่าประเมิน (metric):** ตัวเลขที่บอกว่าโมเดลตรวจถูกหรือพลาดแค่ไหน
- **Precision:** ในสิ่งที่โมเดลบอกว่าพบ มีเท่าไรที่พบถูกจริง
- **Recall:** ในสิ่งที่มีอยู่จริง โมเดลหาเจอได้เท่าไร
- **mAP:** คะแนนรวมที่ใช้ดูความแม่นของกรอบและการแยกคลาส
- **Colab:** พื้นที่เขียนและรัน Python บนเว็บ เหมาะสำหรับฝึกโมเดลโดยใช้เครื่องของ Google
- **Streamlit:** เครื่องมือสร้างหน้าเว็บจาก Python
- **เฟรม (frame):** ภาพนิ่งหนึ่งภาพที่อยู่ในวิดีโอ
- **RGB / BGR:** ลำดับช่องสีของภาพ โปรแกรมต่างชนิดอาจเรียงสีไม่เหมือนกัน
- **`data.yaml`:** ไฟล์บอกตำแหน่งภาพและชื่อคลาสให้ YOLO
- **`best.pt`:** ไฟล์ที่เก็บสิ่งที่โมเดลเรียนรู้ไว้จากรอบฝึกที่ได้ผลดีที่สุด
- **API/รูปแบบส่งข้อมูล:** ข้อตกลงว่าฟังก์ชันหนึ่งรับอะไรและคืนอะไร เพื่อให้เพื่อนเรียกใช้ได้ถูกต้อง
- **โมดูล:** ไฟล์ Python ที่แยกหน้าที่หนึ่งไว้ เช่น `video_processing.py`
- **YOLO:** โปรแกรมสำหรับหาและตีกรอบสิ่งของในภาพ เช่น คนหรือหมวก
- **Ultralytics:** ชุดเครื่องมือ Python ที่ใช้โหลดและฝึก YOLO
- **GPU:** หน่วยคำนวณบนการ์ดจอ ช่วยให้ฝึกโมเดลเร็วขึ้น
- **notebook / cell:** สมุดงานบน Colab / ช่องหนึ่งที่ใส่โค้ดแล้วกดรัน
- **runtime:** เครื่องคอมพิวเตอร์ที่ Colab ให้ notebook ใช้ทำงาน
- **epoch:** หนึ่งรอบที่โมเดลดูภาพฝึกครบทั้งหมด
- **imgsz:** ขนาดภาพที่ส่งเข้าโมเดลตอนฝึก เช่น 640 พิกเซล
- **CLAHE:** วิธีปรับภาพให้ส่วนมืดและสว่างแยกกันชัดขึ้น
- **contrast:** ความต่างระหว่างส่วนสว่างกับส่วนมืดของภาพ
- **path:** ที่อยู่ของไฟล์หรือโฟลเดอร์ในเครื่อง/Colab

# คู่มือคนที่ 2 — หาและเตรียมชุดภาพ

> [!summary] หน้าที่ของคุณ
> หาและตรวจภาพตัวอย่างพร้อมป้ายกำกับให้ตรงกับโจทย์ ก่อนส่งให้คนที่ 3 ใช้ฝึกโมเดล ชุดภาพนี้เป็นพื้นฐานของทั้งระบบ จึงต้องตรวจป้ายก่อนรีบ train

## วิธีทำทีละส่วน

### 1. หา Dataset ที่ใช้ได้

ลองหาใน Roboflow, Kaggle หรือแหล่งข้อมูลสาธารณะอื่น ดูว่าผู้ให้ข้อมูลอนุญาตให้นำไปใช้ในงานเรียนและเผยแพร่ใน GitHub หรือไม่ จดลิงก์และเงื่อนไขไว้

### 2. ตรวจว่าป้ายกำกับตอบโจทย์

เปิดภาพและกรอบตัวอย่างจริง แล้วจดชื่อประเภทตามที่อยู่ในข้อมูล อย่าเปลี่ยนชื่อเองก่อนคุยกับทีม

- ถ้าจะตรวจคนไม่สวมหมวก ให้ดูว่ามีตัวอย่างติดป้าย `no_helmet` จริงหรือไม่
- ถ้ามีแค่ `helmet` ให้แจ้งทีม เพราะโมเดลจะตรวจ “ไม่สวมหมวก” โดยตรงจากข้อมูลนั้นไม่ได้
- ถ้ามีป้าย `person` กับ `helmet` แต่ไม่มี `no_helmet` ให้คุยกันก่อนว่าจะจับคู่สองสิ่งนี้อย่างไร

### 3. ตรวจคุณภาพข้อมูล

เปิดดูภาพหลายแบบ เช่น แสงสว่าง/มืด คนใกล้/ไกล และตรวจว่ากรอบครอบวัตถุถูกต้อง นับจำนวนภาพและจำนวนตัวอย่างในแต่ละประเภท จดภาพซ้ำ ภาพเสีย หรือประเภทที่มีข้อมูลน้อย

### 4. จัดชุดฝึกและชุดตรวจ

แยกภาพเป็น `train`, `validation` และ `test`:

- `train` ให้โมเดลเรียนรู้
- `validation` ใช้ดูผลระหว่างทำ
- `test` เก็บไว้ตรวจผลครั้งสุดท้าย

อย่าให้ภาพเดียวกันอยู่ทั้งชุดฝึกและ test ถ้าหลายภาพมาจากวิดีโอหรือเหตุการณ์เดียวกัน ให้พยายามอยู่ชุดเดียวกัน

### 5. ส่งให้คนที่ 3 ตรวจรูปแบบไฟล์

ส่งไฟล์ zip หรือแชร์โฟลเดอร์ พร้อม `data.yaml` ซึ่งบอกตำแหน่งภาพและรายชื่อประเภท ให้คนที่ 3 ลองเปิดใน Google Colab ก่อนเริ่มฝึก หากข้อมูลมาจาก Roboflow ให้เลือกส่งออกแบบ YOLO

### 6. ทำสรุปข้อมูล

เตรียมตาราง `ประเภท | จำนวนภาพฝึก | จำนวนภาพตรวจระหว่างทำ | จำนวนภาพ test` พร้อมที่มาและเงื่อนไขการใช้ ส่งให้คนที่ 5 นำไปใส่ README/รายงาน

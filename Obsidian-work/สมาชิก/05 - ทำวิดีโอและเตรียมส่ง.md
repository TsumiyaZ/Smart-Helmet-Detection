# คู่มือคนที่ 5 — วิดีโอ ทดสอบ และรวบรวมส่งงาน

> [!summary] หน้าที่ของคุณ
> ทำให้ระบบรับคลิป ตรวจเฟรมทีละภาพ แล้วได้คลิปที่มีกรอบผลลัพธ์กลับมา พร้อมรวบรวมข้อมูลจากเพื่อนให้เป็น README และสื่อสาธิต

## ส่วน A — ทำวิดีโอ

### ทำไมต้องอ่านทีละภาพ

YOLO (เครื่องหาสิ่งของในภาพ) ตรวจภาพนิ่งทีละภาพ ส่วนวิดีโอประกอบด้วยภาพนิ่งจำนวนมาก จึงต้องทำซ้ำกับทุกเฟรม วิดีโอ 10 วินาทีที่ 30 ภาพต่อวินาทีมีประมาณ 300 เฟรม ตัวตรวจภาพจึงถูกเรียกประมาณ 300 ครั้ง

### 1. ตกลงวิธีเรียกกับเพื่อน

- คนที่ 3 ส่งฟังก์ชันตรวจภาพหนึ่งภาพให้
- คนที่ 1 ทำช่องเลือกคลิปและแสดงคลิปผลลัพธ์บนหน้าเว็บ
- คุณทำส่วนที่อ่านคลิป วนทีละเฟรม เรียกฟังก์ชันของคนที่ 3 แล้วเขียนคลิปใหม่

บันทึกข้อตกลงไว้ใน [[Obsidian-work/03 - สัญญาเชื่อมระบบ|ข้อตกลงส่งข้อมูล]] ก่อนเริ่มเชื่อมโค้ด

### 2. เริ่มด้วยคลิปสั้น

เลือก MP4 สั้น ๆ ที่ทุกคนแชร์ได้ ลองเปิดอ่านและเขียนคลิปสำเนาออกมาก่อน โดยยังไม่ต้องตรวจหมวก ถ้าคลิปสำเนาเปิดไม่ได้ ให้แก้ส่วนอ่าน/เขียนวิดีโอก่อน

### 3. ต่อโมเดลเข้ากับแต่ละเฟรม

อ่านภาพหนึ่งเฟรมจากคลิป ส่งให้ฟังก์ชันของคนที่ 3 รับภาพที่มีกรอบ แล้วเขียนภาพนั้นลงไฟล์ผลลัพธ์ ทำซ้ำจนหมดคลิป โค้ดส่วนนี้อยู่ใน `src/video_processing.py`

### 4. ต่อเข้าเว็บ

ให้คนที่ 1 เรียกฟังก์ชันของคุณเมื่อผู้ใช้อัปโหลดคลิป แล้วแสดงความคืบหน้ากับคลิปผลลัพธ์ ถ้าคลิปยาวหรือช้ามาก ให้เริ่มจากคลิปสั้นและบอกข้อจำกัด

### 5. จัดการปัญหาให้เรียบร้อย

- ถ้าไฟล์เปิดไม่ได้ ให้แสดงข้อความบอกสาเหตุ
- ปิดไฟล์วิดีโอทั้งต้นทางและปลายทางเมื่อทำเสร็จหรือเกิดข้อผิดพลาด
- ตรวจว่าคลิปผลลัพธ์เปิดเล่นได้จริง
- อย่าบวกผลตรวจจากทุกเฟรมแล้วเรียกว่า “จำนวนคนไม่ซ้ำ” เพราะคนเดิมอาจปรากฏซ้ำหลายภาพ

## ส่วน B — ทดสอบและรวบรวมเอกสาร

### 1. ทดสอบระบบตั้งแต่ต้นจนจบ

ลองเปิดเว็บ เลือกภาพ ตรวจผล แล้วลองเลือกคลิป ถ้าพบปัญหา จดขั้นตอนที่ทำ ไฟล์ที่ใช้ และสิ่งที่เกิดขึ้น ส่งกลับให้เจ้าของส่วนนั้นแก้

ให้สมาชิกแต่ละคนตรวจงานของตัวเองด้วย คุณรวบรวมรายการปัญหา ไม่จำเป็นต้องแก้โค้ดของทุกคนแทน

### 2. รวบรวม README

ขอข้อมูลจากเพื่อน:

- คนที่ 2: ที่มาและเงื่อนไขการใช้ชุดภาพ จำนวนภาพ และประเภท
- คนที่ 3: วิธีฝึก วิธีโหลดโมเดล และผลที่ได้
- คนที่ 4: วิธีปรับภาพและตัวเลขประเมิน
- คนที่ 1: วิธีเปิดเว็บและวิธีใช้งาน
- คุณ: วิธีตรวจวิดีโอ วิธีดูคลิปผลลัพธ์ และข้อจำกัด

เขียน README ตามสิ่งที่ทำได้จริง อย่าใส่ตัวเลขหรือผลที่ยังไม่ได้วัด

### 3. เตรียมสาธิต

ทำลำดับสั้น ๆ: บอกปัญหา → เลือกภาพ/คลิป → แสดงผลตรวจ → แสดงผลประเมิน → บอกข้อจำกัด เตรียมคลิปผลลัพธ์ไว้ล่วงหน้าด้วย เผื่อเครื่องประมวลผลวิดีโอช้า

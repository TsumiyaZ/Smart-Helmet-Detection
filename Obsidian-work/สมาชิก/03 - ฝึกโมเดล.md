# คู่มือคนที่ 3 — ฝึกโมเดลใน Google Colab

> [!summary] หน้าที่ของคุณ
> นำชุดภาพที่คนที่ 2 ตรวจแล้วไปฝึก YOLO11 ใน Colab ตรวจผล แล้วส่งไฟล์โมเดลกับวิธีเรียกให้คนที่ 1 และ 5

## ก่อนเปิด Colab

ขอให้คนที่ 2 ส่งสิ่งเหล่านี้ก่อน:

- ชุดภาพที่แบ่ง train/validation/test แล้ว
- ไฟล์ `data.yaml`
- ชื่อประเภทตามที่อยู่ในข้อมูล
- ที่มาของข้อมูลและข้อจำกัด

ถ้ายังไม่มีชุดภาพ คุณเตรียม notebook เปล่าและตรวจตัวอย่าง pretrained model ได้ แต่ยังฝึกโมเดลหมวกของทีมไม่ได้

## วิธีฝึกใน Colab ทีละขั้น

### 1. สร้าง notebook และเลือกเครื่องช่วยคำนวณ

เปิด Google Colab แล้วสร้าง notebook ใหม่ (สมุดงานที่แบ่งโค้ดเป็นช่อง ๆ) เลือกเครื่องทำงานที่มี GPU หากมีให้เลือก GPU ช่วยลดเวลาฝึก แต่ชนิดและจำนวนที่ให้ใช้ขึ้นกับบัญชี/เวลานั้น

### 2. เอาชุดภาพเข้า Colab

เลือกวิธีใดวิธีหนึ่ง:

- upload ZIP เข้า Colab แล้วแตกไฟล์
- หรือเก็บ ZIP/โฟลเดอร์ไว้ใน Google Drive แล้วเชื่อม Drive กับ notebook

จำตำแหน่งไฟล์ `data.yaml` ให้ได้ เพราะต้องใส่ path นี้ในคำสั่งฝึก

### 3. ตรวจรูปแบบข้อมูล

เปิดดู `data.yaml` ว่ามีตำแหน่งชุด train/validation และรายชื่อประเภทตรงกับที่คนที่ 2 บอกหรือไม่ ตรวจว่าโฟลเดอร์ภาพและไฟล์ป้ายกำกับอยู่ครบ หาก path ผิด ให้หยุดแก้ก่อน train

### 4. ติดตั้งและโหลด YOLO11

ใส่โค้ดใน cell (ช่องโค้ด) ของ Colab แล้วกด Run:

```python
!pip install -q ultralytics

from ultralytics import YOLO

# n คือรุ่นเล็ก เหมาะสำหรับเริ่มทดลอง
model = YOLO("yolo11n.pt")
```

YOLO11 จะเริ่มจากโมเดลที่ฝึกมาก่อน แล้วเรียนรู้ประเภทของ Dataset ทีมต่อ [คู่มือ YOLO11 ทางการ](https://docs.ultralytics.com/models/yolo11)

### 5. สั่งฝึกด้วย Dataset ของทีม

แทน path ตัวอย่างด้านล่างด้วยตำแหน่งจริงของ `data.yaml`:

```python
results = model.train(
    data="/content/โฟลเดอร์ข้อมูล/data.yaml",
    epochs=50,
    imgsz=640,
)
```

`epochs` คือจำนวนรอบที่โมเดลดูข้อมูลเพื่อเรียนรู้ ส่วน `imgsz=640` คือขนาดภาพที่ส่งให้โมเดลดู ตัวเลข 50 เป็นจุดเริ่มทดลอง ปรับตามเวลาและผลจริง ถ้าข้อมูลโหลดไม่ได้ ให้ตรวจที่อยู่ไฟล์และรูปแบบข้อมูลก่อนเพิ่มจำนวนรอบ

### 6. ตรวจผลฝึก

ดูตัวเลขและภาพที่ Colab สร้างไว้ ตรวจว่าโมเดลวาดกรอบถูกตำแหน่งและเรียกชื่อประเภทถูกหรือไม่ จากนั้นตรวจผลบนชุด test ที่คนที่ 2 แยกไว้ เอกสาร [รูปแบบข้อมูลตรวจจับของ YOLO](https://docs.ultralytics.com/datasets/detect) อธิบายการจัดภาพ ป้ายกำกับ และไฟล์ตั้งค่าข้อมูล

อย่าใช้ผลจากภาพ train มาอ้างว่าเป็นผลทดสอบ ถ้ามีป้ายกำกับ test ให้ประเมินบน test; ถ้าไม่มี ให้บอกชัดว่าใช้ validation

### 7. เก็บไฟล์โมเดลออกจาก Colab

หาไฟล์ `best.pt` ในโฟลเดอร์ผลฝึก `weights` แล้วคัดลอกไป Google Drive หรือดาวน์โหลดลงเครื่อง Colab อาจลบไฟล์เมื่อ session หมดอายุ จึงอย่าปิดก่อนเซฟและเปิดไฟล์ตรวจว่าขนาดไม่เป็นศูนย์

ส่งให้ทีม:

- `best.pt` หรือ Drive link ที่ทุกคนเปิดได้
- ชื่อประเภทและลำดับ class ID
- คำสั่งฝึกและ path ของ `data.yaml`
- ผล validation/test และตัวอย่างภาพที่โมเดลตรวจ
- ข้อผิดพลาดที่ยังเจอ เช่น พลาดคนไกลหรือสับสนบางประเภท

## ส่งงานต่ออย่างไร

- **ให้คนที่ 1:** ฟังก์ชันตรวจภาพหนึ่งภาพ พร้อมรูปแบบค่าที่คืน เพื่อแสดงในหน้าเว็บ
- **ให้คนที่ 4:** weight และ split ที่ใช้ เพื่อวัดผลและเทียบก่อน/หลังปรับภาพ
- **ให้คนที่ 5:** ฟังก์ชันตรวจภาพหนึ่งเฟรม เพื่อวนตรวจวิดีโอ

ถ้าไฟล์ `best.pt` ใหญ่เกินกว่าจะเก็บใน GitHub ให้ส่งผ่าน Drive และเขียนวิธีดาวน์โหลดไว้ใน README อย่า commit ไฟล์โมเดลว่างหรือไฟล์ตัวอย่างชื่อเดียวกันทับไฟล์จริง

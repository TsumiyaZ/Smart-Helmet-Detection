# คนที่ 1 — Streamlit และรวมระบบ

> [!abstract] ผลลัพธ์ของบทบาทนี้
> ทำหน้า Streamlit และประสบการณ์ผู้ใช้: upload, เลือก confidence/preprocessing, แสดงผลภาพ/วิดีโอและสถิติ งานนี้เป็นเจ้าของ UI และ app flow; คนที่ 5 เป็นเจ้าของวิดีโอ frame pipeline

## งานตามวัน

### Day 1
- [ ] สร้างโครงหน้า Streamlit ใน `app.py` และแสดงหัวข้อ/วิธีใช้/สถานะโมเดล
- [ ] นัดตกลง data contract กับคนที่ 3 และ 4 ก่อนเขียน integration
- [ ] แสดง error ที่ผู้ใช้แก้เองได้ เช่น ไม่พบไฟล์ weight หรือรูปแบบไฟล์ไม่รองรับ

**ส่งมอบ:** โครงแอปที่ `streamlit run app.py` เปิดได้ และสัญญาฟังก์ชันที่ตกลงแล้ว

### Day 2
- [ ] ทำ upload ภาพและแสดงภาพต้นฉบับ พร้อมกำหนดส่วน UI สำหรับวิดีโอ (ยังไม่ต้องประมวลผลเฟรม)
- [ ] ทำพื้นที่ผลลัพธ์ที่รับ annotated image, detection list และ counts
- [ ] ใช้ mock output ชั่วคราวเฉพาะตอน model API ยังไม่พร้อม; ทำเครื่องหมายชัดว่าเป็น mock และลบทิ้งก่อนส่ง

**ส่งมอบ:** UI ใช้งานได้โดยไม่ต้องรอ train เสร็จ

### Day 3
- [ ] เชื่อมฟังก์ชัน `predict_image` จากคนที่ 3
- [ ] เชื่อม preprocessing จากคนที่ 4 ด้วย toggle/ตัวเลือกที่เข้าใจง่าย
- [ ] เพิ่ม confidence threshold และสรุปจำนวนตาม class
- [ ] ทดสอบ path ภาพสี/RGB/BGR เพื่อป้องกันสีเพี้ยน

**ส่งมอบ:** MVP ภาพ end-to-end และ screenshot

### Day 4–5
- [ ] ต่อ UI วิดีโอเข้ากับ `process_video` ของคนที่ 5; แสดง progress, video output และ error ที่ผู้ใช้แก้ได้ คนที่ 5 เป็นผู้ดูแลการอ่าน/ประมวลผล/เขียนเฟรม
- [ ] ตรวจการใช้หน่วยความจำ/เวลารันและเพิ่มข้อความสถานะระหว่างประมวลผล
- [ ] รับ branch/ไฟล์จากทุกคนและทดสอบ clean start ก่อน release

**ส่งมอบ:** แอปสุดท้ายพร้อม demo และขั้นตอนรันที่ผ่านการตรวจ

## เกณฑ์รับงาน

- [ ] หน้าแอปไม่ crash เมื่อไม่มีไฟล์ weight; แสดงข้อความชัดเจน
- [ ] ภาพผลลัพธ์เป็นสีถูกต้อง มี box และชื่อคลาสที่ตรงกับ dataset
- [ ] ผลนับมาจาก detection output จริง ไม่ hard-code
- [ ] ไม่ปิดบัง error สำคัญด้วย `except` เปล่า
- [ ] วิธีเริ่มแอปใน README ใช้ได้ตามจริง

## การช่วยเหลือข้ามงาน

ถ้า integration ติดเพราะ model API ยังไม่มา ให้ใช้ mock เพื่อทำ UI ต่อ แต่ส่งข้อความบอกคนที่ 3 ว่าต้องการ output แบบใดและกำหนดเวลาส่งให้ชัด ถ้าติด dependency ให้คนที่ 5 ช่วยทดสอบ clean environment
